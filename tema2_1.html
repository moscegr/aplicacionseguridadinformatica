Administración e Instalación de Controles (Hardening)

Dejamos el papel y pasamos a la terminal. Es hora de implementar técnicamente el Plan de Seguridad (Fase DO del ciclo Deming). Vamos a endurecer el sistema (Hardening) cerrando puertas de red, bloqueando permisos locales y cifrando túneles de comunicación.

Concepto Clave - Defensa en Profundidad (Defense in Depth): Nunca confíes en un solo candado. Si el intruso pasa el Firewall Perimetral, se debe topar con el Firewall Local. Si pasa ese, se topa con un Cifrado de archivos. Retrasar al hacker da tiempo al Blue Team para reaccionar.

Laboratorios de Configuración

Hardening del Sistema Operativo y Cuentas

Glosario Técnico:

  • Hardening: Proceso de reducción de vulnerabilidades de un sistema operativo, eliminando software innecesario, cerrando puertos no usados y aplicando parches.
  • WSUS / SCCM: Servidores de actualizaciones centralizadas. En empresas no dejes que cada PC se actualice sola por internet; ahorras ancho de banda descargando una vez y empujando el parche por la red LAN.
  • UAC (User Account Control): La pantalla de Windows que se oscurece y pide permisos de Administrador antes de instalar algo, bloqueando instalaciones sigilosas de malware.

Lógica de Control de Actualizaciones:

[POLÍTICA DE GPO (Group Policy Object)]
Path: Configuración del equipo > Plantillas adm. > Componentes de Windows > Windows Update
Ajuste: Configurar Actualizaciones Automáticas -> "Habilitado"
Opcion: 4 (Descargar automáticamente y programar la instalación)
Hora: Día 0 (Todos los días) a las 03:00 AM.

5 Ejercicios Prácticos:

  1. Creación de Cuentas Limitadas: Crea un usuario local estándar en Windows. Intenta instalar un programa (ej. 7-Zip). Observa y documenta cómo el sistema detiene la ejecución pidiendo credenciales Admin.
  2. Forzar Políticas de Contraseña (Local Secpol): Abre secpol.msc. Navega a "Políticas de contraseñas". Configura: Longitud mínima = 10, y "Las contraseñas deben cumplir los requisitos de complejidad". Intenta cambiar tu clave a "12345" y observa el error del sistema.
  3. Auditoría de Software Basura (Bloatware): Abre el Panel de Control. Haz una lista del software preinstalado que la empresa NO necesita (juegos, utilerías obsoletas). Explica por qué borrarlo reduce la "Superficie de Ataque".
  4. Configuración del UAC: Cambia el nivel del UAC al máximo (Avisar siempre). Documenta en qué escenarios (modificar registros, instalar .exe) el sistema interviene.
  5. Manual de Procedimiento (Entregable): Escribe un mini-manual de media cuartilla con capturas de pantalla de los pasos para configurar actualizaciones obligatorias en Windows 10/11.

Control Lógico: Permisos NTFS y Cifrado de Datos

Glosario Técnico:

  • NTFS (New Technology File System): Sistema de archivos moderno de Windows que permite otorgar permisos extremadamente granulares a nivel de archivo/usuario.
  • Cifrado (Encryption): Convertir texto plano (legible) en texto cifrado (ilegible) usando un algoritmo matemático y una llave criptográfica.
  • BitLocker: Herramienta nativa de Windows para cifrar el disco duro completo. Si roban la laptop y sacan el disco físico para leerlo en otra PC, solo verán basura incomprensible.

5 Ejercicios Prácticos:

  1. Implementación NTFS (Permisos de Lectura): Crea una carpeta "Auditoria_RH". Da clic derecho > Propiedades > Seguridad. Elimina al grupo "Usuarios" y agrega a un usuario específico dándole solo permiso de "Lectura". Comprueba que no puede borrar archivos dentro.
  2. El Peligro del Control Total: Explica, probando en el laboratorio, por qué darle permisos de "Control Total" a un empleado estándar sobre una carpeta compartida de red facilita la propagación instantánea de Ransomware.
  3. Cifrado EFS Nivel Archivo: Crea un documento de texto "Misiones_Drones.txt". Clic derecho > Propiedades > Opciones Avanzadas > "Cifrar contenido para proteger datos". Aplica. Inicia sesión con otra cuenta de usuario local e intenta abrirlo. Reporta el mensaje de "Acceso Denegado".
  4. Investigación Bitlocker (Full Disk Encryption): Investiguen qué es el chip TPM de las tarjetas madre modernas y cómo hace sinergia con BitLocker para arrancar la PC de manera blindada.
  5. Destrucción de Accesos (Revocación): Simulen el despido de un empleado. Procedan a deshabilitar su cuenta de usuario en compmgmt.msc (No borrarla, solo deshabilitarla por temas forenses). Escriban la justificación técnica.

Configuración de Red: Firewalls Locales y Perimetrales

Glosario Técnico:

  • Firewall (Cortafuegos): Filtro de red que examina paquetes entrantes y salientes, y decide si los bloquea o deja pasar basado en un set de reglas IP/Puerto.
  • Regla Inbound / Outbound: Regla de entrada (lo que intenta conectarse a ti) vs de salida (lo que tú intentas mandar a internet). Un buen Firewall bloquea por defecto todo lo que entra.
  • Puertos (Ports): Puertas virtuales. Ej: El puerto 80 es para páginas web (HTTP). El 3389 es RDP (Escritorio Remoto), puerto favorito de los atacantes, debe cerrarse siempre.

Sintaxis Típica de Regla Firewall de Producción:

[REGLA DE BLOQUEO RDP]
Nombre: BLOCK_REMOTE_DESK
Dirección: IN (Entrada)
Protocolo: TCP
Puerto Local: 3389
Acción: BLOCK (Bloquear Conexión)
Perfiles: Dominio, Privado, Público

5 Ejercicios Prácticos:

  1. Defensa Activa (Windows Defender Firewall): Abre `wf.msc`. Crea una nueva regla de entrada. Bloquea el puerto TCP 21 (FTP). Intenta usar un cliente FTP para comprobar que el sistema a nivel de kernel rechaza la conexión.
  2. Escaneo de Puertos Enemigo (Nmap / Comando Netstat): Abre la terminal (cmd o powershell) y escribe `netstat -ano`. Analicen la lista de puertos en estado "LISTENING". Estos son los huecos activos en su armadura que esperan conexión exterior.
  3. Aislamiento de Programas (Bloqueo Outbound): Crea una regla de salida en el firewall. En vez de bloquear un puerto, bloquea el archivo `.exe` del navegador web (Edge/Chrome). Intenta navegar. Acabas de aprender cómo silenciar malware que intenta robar datos hacia fuera.
  4. Análisis Perimetral: Dibuja un diagrama de red básico de una empresa (Nube -> Router ISP -> Firewall Perimetral -> Switch Interno -> PC Usuario). Explica dónde se coloca físicamente un cortafuegos de hardware (como Fortinet o pfSense).
  5. Reglas por Defecto de Negación (Default Deny): Explica este concepto de ingeniería militar: "Se bloquea absolutamente todo tráfico de entrada. Únicamente se crea una regla para permitir (Allow) los puertos estrictamente vitales (ej. 443)".

Protección Dinámica: Antivirus, Antispyware e IDS

Glosario Técnico:

  • Firmas vs Heurística: Los antivirus viejos detectaban virus buscando una "firma" (huella digital) conocida en su base de datos. Los AV modernos usan "Heurística" (IA) para detectar comportamiento anómalo aunque el virus sea totalmente nuevo (Zero-Day).
  • IDS / IPS (Intrusion Detection/Prevention System): Software o hardware (como Snort) que lee en tiempo real la "forma" de los paquetes de red, olfateando tráfico de fuerza bruta o escaneos sospechosos y cortando la conexión instantáneamente (IPS).
  • Falsos Positivos: Cuando el antivirus marca como virus a un programa legítimo de la escuela porque tiene comportamiento extraño (ej. un script de Python compilado).

5 Ejercicios Prácticos:

  1. Políticas de Escaneo Activo: Accede a las configuraciones avanzadas del antivirus local. Documenta el proceso para programar un "Examen Completo" (Full Scan) todos los viernes a las 6:00 PM.
  2. El Archivo EICAR: El EICAR es un archivo de texto seguro mundialmente usado para probar si el motor de un antivirus está activo. Descarga la cadena de texto oficial (búscala online), guárdala en un `.txt` y observa cómo el antivirus lo aniquila en milisegundos.
  3. Gestión de Exclusiones (Whitelisting): Tu script de pilotaje de drones fue bloqueado por el antivirus local. Crea una regla de "Exclusión" de carpeta específica para que el motor ignore esa zona del disco duro.
  4. Detección de Spyware (Keyloggers): Investiga el funcionamiento lógico de un "Keylogger" (Spyware que captura todo lo tecleado). Explica cómo interfiere el módulo de "Protección de Identidad/Antispyware" a nivel de memoria RAM para bloquearlo.
  5. Investigación de Snort (NIDS): Realiza una ficha de media hoja sobre "Snort" (software libre). Explica cómo utiliza reglas escritas en texto para alertar si detecta 100 intentos fallidos de logeo al puerto SSH de un servidor.

Túneles Seguros: Protocolos, IPSEC y Criptografía de Red

Glosario Técnico:

  • HTTP vs HTTPS: En HTTP todo el tráfico web (incluyendo passwords) viaja en texto plano por el aire. En HTTPS (sobre SSL/TLS), todo el paquete de red viaja fuertemente cifrado mediante matemáticas de clave pública/privada.
  • VPN (Virtual Private Network): Extiende la red privada de tu empresa a través del internet público, creando un "tubo" cifrado desde la casa del empleado hasta el servidor central.
  • IPSEC (IP Security): Conjunto de protocolos que autentica y cifra cada uno de los paquetes de datos que fluyen por la conexión VPN.
  • Man-in-the-Middle (MITM): Ataque donde el hacker se sienta "en medio" del router y la PC de la víctima, robando todo el tráfico de la red WiFi abierta del Starbucks.

Inspección Criptográfica del Navegador:

[CERTIFICADO SSL/TLS DE BANCO]
Navegador verifica: ¿La llave pública coincide con el dominio real?
Algoritmo: AES-256 (Cifrado militar simétrico irrompible).
Resultado: El Candado Verde. Ningún ISP, Hacker o Gobierno puede ver la contraseña en tránsito.

5 Ejercicios Prácticos:

  1. Auditoría de Certificados X.509: Abre tu cuenta de correo o banco en el navegador. Haz clic en el candado junto a la URL y mira la información del Certificado. Documenta quién lo emitió (CA - Autoridad Certificadora) y cuándo expira.
  2. El Peligro del WiFi Abierto (MITM Simulado): Haz un diagrama explicando detalladamente cómo, sin una VPN o HTTPS, un intruso con el software `Wireshark` en una red pública puede interceptar la foto confidencial que el dron está transmitiendo a la base.
  3. Análisis del Protocolo SSH vs Telnet: Investiguen. Telnet es un protocolo antiguo para controlar servidores; SSH (Secure Shell) es el moderno. Expliquen la diferencia estructural (cifrado por túnel) entre usar el puerto 23 vs el puerto 22.
  4. Generación de Llaves Públicas (PGP/SSH-Keygen): En Linux/Colab investiga cómo funciona el comando `ssh-keygen`. Entiende que esto crea dos archivos: uno privado (que nunca debes compartir) y uno público (el candado abierto). Escribe cómo previene el robo de contraseñas.
  5. Manual Técnico Final RA 2.1 (Entregable): Compila en un documento PDF todas las capturas y configuraciones que hicieron: Política de Contraseñas, Regla de Firewall, Exclusión de Antivirus y revisión de Certificado HTTPS. Este es su manual de Hardening Básico.
